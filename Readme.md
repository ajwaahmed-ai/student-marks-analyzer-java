
# Student Marks Analyzer (Java)

A beginner-friendly Java application that calculates
a student's average marks and assigns a grade.

## Features
- Accepts student name and subject marks
- Calculates average marks
- Assigns a grade based on the average

## Requirements
- Java JDK 17 or later

## How to Run

Compile:
```bash
javac Main.java
```

Run:
```bash
java Main
```
